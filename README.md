# Nefertiti Nails – landing oldal

Egyszerű, statikus oldal (HTML + CSS). GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Amit át kell írni
- `index.html` → a "Hely & Elérhetőség" részben a cím és a telefonszám (TODO megjegyzések).
- `adatvedelem.html` → az impresszum adatai (név, cím, adószám, e-mail) a `[...]` helyeken.
- `img/galeria-1..6.svg` → cseréld saját fotókra (és írd át az `<img src>` útvonalakat).
